Windows 链接下载工具 · 窗口分享版

使用条件：Windows 10/11 64 位电脑，已安装 Chrome 或 Edge 浏览器，可以联网。
包内自带 Python，无需另行安装，也不需要管理员权限。

一、开始使用

1. 先把整个压缩包解压到可以写入的文件夹，例如 D:\Codex\视频链接下载工具。
   不要直接在压缩包里双击运行，不要只复制其中一个文件。
2. 双击“视频下载工具.exe”打开中文窗口，无需打开 PowerShell 或输入命令。
3. 在“作品链接”框中粘贴抖音或 B 站链接，或点击“粘贴链接”。可以粘贴整段分享文字，多条作品请每条占一行。
4. 如需更改保存位置，点击“选择…”，然后点击“开始下载”。
   首次下载会自动联网准备组件，请等待；窗口显示当前状态及处理记录，不会显示虚假的下载百分比。
5. 完成后点击“打开文件夹”。默认保存在本工具目录下的“下载内容”，按平台和作品编号分类。
6. 下载期间可点击“停止”；已完成的文件保留，未完成的链接可以重新下载。关闭窗口也会先停止当前任务。

首次运行会下载 FFmpeg 和 BBDownNext 并检查校验值，保存在 .tools，后续运行会复用。
“开始下载.cmd”是打开同一窗口的兼容入口；推荐直接双击 EXE。

视频保存为 MP4，保留声音；图文保存原图和能获取到的正文。
标题、发布时间、公开定位能获取到时会附带保存，未知信息标记为“未获取”。
相同作品已完整下载时会跳过；不会覆盖已有但未经校验的目录。

二、需要登录时

在窗口中点击“登录抖音”，本人在打开的官方页面完成登录，然后关闭整个专用浏览器窗口，再开始下载。
点击“登录 B 站”后会打开下载器的扫码窗口，按提示由本人完成登录，无需输入命令。

这个分享包不含分享者的账号、Cookie 或登录状态。每个人使用自己的账号。
登录入口已提供，扫码登录及登录态复用尚未实测。

登录后，抖音登录数据保存在 .session，B 站登录数据保存在 .tools 中下载器所在目录。
这些目录以及 .work、下载内容可能包含你的个人数据；不要把使用后的整个文件夹直接转发给别人。
继续分享时请发送收到的原始压缩包。登录状态会过期，需要时重新登录。

三、指定目录、批量处理（可选）

在工具文件夹空白处右键，选择“在终端中打开”，在 PowerShell 输入：

  & '.\.runtime\python.exe' -B '.\grab.py' '粘贴作品链接' --output 'D:\我的视频'

准备 UTF-8 编码的 links.txt，每行一个链接：

  & '.\.runtime\python.exe' -B '.\grab.py' --file '.\links.txt' --output 'D:\我的视频'

这些命令仅供习惯命令行的用户使用，日常下载和批量粘贴均可在窗口内完成。

四、常见问题

· 首次下载组件失败：检查网络能否访问 pypi.org、files.pythonhosted.org 和 github.com，然后重新运行。
· 提示找不到浏览器：先正常安装 Chrome 或 Edge。部分仅为单个用户安装的浏览器路径可能无法自动识别。
· 窗口程序使用 Windows 的 .NET Framework 4.5 以上组件，正常的 Windows 10/11 通常已具备。
· 抖音加载失败：关闭本工具打开的专用登录窗口，再重试。验证码需要本人处理。
· 有登录状态仍下载失败：作品权限、付费限制、平台风控或页面更新可能导致失败，不保证所有链接长期可用。
· B 站多 P 视频：只下载链接指定的分 P，未指定时下载第 1 P。
· 画质取决于平台本次提供的流，不代表作者上传前的源文件。
· 第一次启动的联网下载只把组件写入工具目录，不会向系统安装 Python 包。

包内保留 grab.py、ui 窗口源码和 tests 测试。检查命令：

  & '.\.runtime\python.exe' -B -m unittest discover -s tests -v

第三方来源和许可证见 THIRD_PARTY.txt、.runtime\LICENSE.txt。
