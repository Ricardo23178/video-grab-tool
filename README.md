# Windows 链接下载工具

把抖音或 B 站的作品链接交给这个项目，在本机保存原视频 MP4、图片或原文。无需继续把链接发送给聊天助手。视频复制封装，保留声音，不做重新编码或 AI 内容分析。

## 直接使用

### 中文窗口

本机界面已美化为浅灰底、白色圆角卡片和靛蓝主按钮，左右分别呈现下载操作和状态记录；包含输入提示、等待 / 完成状态和窗口缩放适配。本轮按要求只更新本机程序，未重新生成分享包。

双击项目中的 `视频下载工具.exe`，粘贴抖音 / B 站链接或完整分享文字，选择保存位置，点击“开始下载”。支持粘贴多条链接；状态和处理记录显示在窗口内，下载期间可停止，完成后可直接打开文件夹。默认保存到程序目录下的 `下载内容`。

下载在后台进行，首次缺少组件时自动联网准备，不需要输入 PowerShell 命令。登录入口也在窗口中：抖音打开官方浏览器页面；B 站打开扫码窗口，均由本人操作。源码目录中的 EXE 使用已安装的 Python；分享包优先使用内置 Python。

### 分享给朋友

`python -B package_share.py` 会在同级的 `分享包` 文件夹生成 Windows x64 便携 ZIP：内置官方 Python 运行环境、窗口 EXE 和使用说明。朋友完整解压后双击 `视频下载工具.exe` 即可使用。首次联网准备 FFmpeg / BBDownNext，以后复用。构建时按文件白名单打包，不包含 `.session`、`.tools`、`.work`、Git 历史或下载原件。朋友需要使用自己的登录状态。窗口使用 Windows 自带的 .NET Framework，无需安装大型界面框架。

### 本机命令行

打开 PowerShell：

```powershell
cd 'D:\Codex\视频解析项目'

# 把链接放在引号里，也可以粘贴整段抖音分享文字
.\grab.ps1 'https://v.douyin.com/8_UurbIXX4g/'

# 指定保存文件夹
.\grab.ps1 'https://v.douyin.com/8_UurbIXX4g/' -OutDir 'D:\我的视频'

# 交互粘贴：每次粘贴一条分享文字，回车下载；q 退出
.\grab.ps1

# 每行一个链接，批量处理
.\grab.ps1 -InputFile '.\links.txt' -OutDir 'D:\我的视频'
```

也可直接使用 Python，不依赖 PowerShell 脚本执行策略：

```powershell
python -B .\grab.py 'https://v.douyin.com/8_UurbIXX4g/' --output 'D:\我的视频'
python -B .\grab.py --file .\links.txt
```

默认输出到 `D:\Codex\视频资料\抖音或B站\作品编号\`，其中包含原视频 / 原图和简短信息文件。公开定位未获取到时明确标记“未获取”，不会推测。重复下载前核对已保存文件的大小和 SHA256；文件被改动或目录已有其他内容时停止该项，不覆盖。

标题、发布时间和公开定位属于能获取时附带保存的信息；核心交付是原件。B 站图文保留下载器导出的正文与图片，视频的简短信息不保证包含完整平台元数据。

## 首次安装与依赖

分享包自带 Python；直接使用源码命令行时需要 Python 3.11 以上。两种方式都需要 Chrome 或 Edge。当前电脑已具备这些环境。工具会优先使用项目 `.tools`、同级 `D:\Codex\tools` 或系统 PATH 中的 FFmpeg、BBDownNext。

```powershell
.\grab.ps1 -Setup
# 或
python -B .\grab.py --setup
```

依赖缺失时下载到项目 `.tools`，临时文件放在 `.work`，不向 C 盘安装 Python 依赖。FFmpeg 来自 imageio-ffmpeg 0.6.0 的官方 PyPI 包，B 站下载器为 [BBDownNext v2.3.0](https://github.com/KaiHuaDou/BBDownNext/releases/tag/v2.3.0)，均检查 SHA256。网络不通时会报告错误，不会修改全局 Python 环境。

## 需要登录时

推荐使用窗口中的登录按钮，也可由你本人在命令行运行：

```powershell
.\grab.ps1 -Login douyin
.\grab.ps1 -Login bilibili
```

抖音使用独立浏览器目录 `.session\douyin`；本人在官方页面登录后，关闭整个专用浏览器窗口，再下载。B 站调用 BBDownNext 自带的扫码登录。登录状态只保存在本机，不导出或打印 Cookie。Cookie 可能失效，需要时重新登录；这不是永久授权。

此前助手环境的自动审批拒绝过启动登录窗口，因此登录命令需要由你本人运行；不能把该步骤视为已在助手环境验证通过。

## 范围与限制

- 接受具体作品的官方长链接、抖音短链接、b23.tv 短链接。支持 UTF-8 / 带 BOM 的批量清单，一项失败继续下一项。
- B 站视频只下载链接指定的分 P；未指定时下载第 1 P，不扫描主页或整个收藏夹。
- 抖音视频通过本机浏览器加载作品页，读取默认脱敏网络记录中的媒体地址；不启用远程调试端口，不提取个人浏览器 Cookie。浏览器会预取推荐内容，工具仅使用最先播放的原视频与音频。
- 抖音图集只保存能在作品图片区明确识别出的图片与正文；B 站图文由 BBDownNext 导出。无法可靠识别时报告失败，不保存评论区、头像或推荐内容充当作品。
- 图集页面提供总张数时，必须与下载图片数一致；分离视频流缺少音频时报告失败，避免保存成无声视频。
- 付费、私密、已删除、验证码、风控、平台页面变化等可能导致失败。不会把试看片段当作完整视频，也不会绕过访问权限。
- 图片与正文支持情况以本项目实际验证记录为准，不承诺所有页面类型可用。视频仅保证下载到平台本次提供的流，不声称取得作者上传前的源文件或最高画质。
- 退出码：`0` 全部成功或跳过，`1` 有下载失败，`2` 输入或配置错误，`130` 主动中断。
